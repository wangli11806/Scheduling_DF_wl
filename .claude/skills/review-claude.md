# 审查 .claude 配置文件

对 `.claude/` 目录进行全面审查，确保指令清晰、高效、无冲突。

## 执行步骤

### 步骤 1: 收集全部配置

读取以下所有文件：
- `.claude/CLAUDE.md`
- `.claude/rules/*.md`
- `.claude/skills/*.md`
- 项目 `Readme.md`（作为对照基准）
- 项目相关的 memory 文件

### 步骤 2: 交叉审查

按以下维度逐条检查：

**过时检查**
- CLAUDE.md 中的技术栈、项目结构与实际代码是否一致
- rules 中的组件/API/流程是否还存在
- skills 中的凭据/路径/命令是否还有效
- 已废弃的功能页面是否仍在文档中

**冗余检查**
- 同一信息是否在 CLAUDE.md + rules + README.md 中重复
- 不同 rule 文件之间是否有内容重叠
- memory 中是否已有对应的 rule（可归档）

**冲突检查**
- 不同文件对同一件事是否给出矛盾指令
- rules 之间是否有互斥的行为规范
- CLAUDE.md 索引的规则条目是否与实际文件名一致

**效率评估**
- CLAUDE.md 是否简洁（入口索引，不存细节）
- rules 是否精准（每条规则有明确触发条件）
- skills 步骤是否完整可执行

### 步骤 3: 输出审查报告

```markdown
## 审查报告 YYYY-MM-DD

### 过时项
- [文件名:行号] 具体问题 → 建议修复

### 冗余项
- [文件A] 与 [文件B] 重复 → 建议保留A、精简B

### 冲突项
- [文件A] 说X，[文件B] 说Y → 建议统一为X

### 效率改进
- [文件名] 具体优化建议
```

### 步骤 4: 等待确认

将报告呈现给用户，逐项确认后再执行修复。
