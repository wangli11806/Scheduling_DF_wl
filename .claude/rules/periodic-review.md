# .claude 文件定期审查

## 规则

**每 7 天自动审查一次 `.claude/` 目录下的所有配置文件，检查是否有过时、冗余或相互冲突的指令。**

## 审查范围

| 文件 | 检查重点 |
|------|----------|
| `CLAUDE.md` | 技术栈是否过时、项目结构是否与实际一致、链接是否有效 |
| `rules/*.md` | 规则是否重复、是否与 CLAUDE.md 冲突、是否还有效 |
| `skills/*.md` | 步骤是否过时、凭据是否变更 |
| `memory/*.md`（项目相关） | 是否已有对应的 rule、是否可归档或删除 |

## 审查流程

1. 读取 `.claude/` 全部文件
2. 读取 `Readme.md` 作为对照基准
3. 逐条检查：
   - **过时**：描述的技术/流程/凭据与当前实际情况不符
   - **冗余**：同一信息出现在多个文件中（以 rules 为准，其他文件只保留索引）
   - **冲突**：两个文件对同一件事给出不同指令
4. 输出审查报告，列出问题和建议
5. 请用户确认后执行修复

## 清理原则

- 每条信息只有一个权威来源
- CLAUDE.md 是入口索引，不存细节
- rules/ 是详细行为规范
- skills/ 是执行流程
- memory/ 是临时教训，长期有效的应升级为 rule

## 注意

- 只提建议不动手，等用户确认
- 报告要标出具体文件名和行号
